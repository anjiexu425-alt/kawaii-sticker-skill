## 1. 角色概述 (Overview)

胖墩是一只**奶白色、圆滚滚的幻想系小萌宠**，整体介于垂耳兔与幻想小精灵之间。性格视觉上软萌、单纯、活泼、有一点憨憨的感觉，但不能呆板——核心特点是**眼神非常有灵气、情绪丰富**。画风为**手绘绘本 × 日系萌系**（柔软铅笔/细线稿、轻微手绘纹理、细腻绒毛、柔和低饱和配色）。

## 2. 画风（style_anchor）

> `style_anchor` 由档案画风决定（SKILL.md §5-8 / PROMPT_CONTRACT §2）：

**手绘绘本 × 日系萌系 (hand-drawn picture-book × Japanese kawaii: soft pencil/light linework, gentle hand-drawn texture, fine fluffy fur, soft low-saturation palette)**

- 柔软铅笔 / 细线稿；轻微手绘纹理；细腻绒毛质感。
- 柔和、低饱和配色；圆润造型。
- **不要**变成 3D 玩偶、迪士尼式光滑渲染或普通扁平卡通。

## 3. 固定外形特征 (Fixed Visual Characteristics)

| 特征 | 描述（必须稳定） |
|---|---|
| 体型 | 小巧、胖乎乎，整体呈**圆润梨形**；头大、身体短胖、小短腿 |
| 毛发 | 奶油白 / 暖象牙白，细腻柔软的绒毛质感（**不是**纯白塑料感） |
| 头顶 | **一撮明显向上翘起、略凌乱的蓬松呆毛**——重要识别特征 |
| 耳朵 | 两只**非常长的长垂耳**，自然垂在脸部两侧；外侧奶白，内侧偏浅灰米色，带少量不规则灰褐色斑点 |
| 眼睛 | **非常大的深棕黑圆眼**，水润明亮、有明显高光；眼神必须有情绪和互动感（视线有方向） |
| 眉毛 | 两条**短短的浅棕色眉毛**，随表情明显变化 |
| 鼻子 | 很小的**深棕色三角鼻** |
| 嘴巴 | 小巧；默认开心状态微张、露粉色小舌头；不同表情允许明显改变嘴型 |
| 脸颊 | 两侧带淡淡**粉色腮红** |
| 手 | 两只短小圆润的前爪，默认放胸前；可做捂脸、叉腰、指人、鼓掌、抱东西等动作 |
| 脚 | 两只非常短、圆圆的小脚 |
| 尾巴 | **大型蓬松长尾巴**，向身体右侧弯曲；奶白带灰褐色斑点——**非常重要的识别特征** |
| 斑点 | 灰褐色斑点主要出现在**长耳、身体侧面和尾巴**，数量适中且不规则；**不要每张图随机变成完全不同的花纹** |

## 4. 表情包表现要点 (Sticker Expression Notes)

**最重要**：胖墩的萌点不是单纯"大眼睛"，而是 **"大眼睛 + 有方向的视线 + 灵活眉毛 + 明确嘴型 + 身体动作"**。

- **允许大幅变化**：眼神、眉毛、嘴巴、动作——做「无语」「生气」「委屈」「震惊」「偷笑」「求求了」「开心」「嫌弃」等表情时尽情变化。
- **必须保持稳定**：头顶呆毛、长垂耳、梨形胖身体、大蓬松尾巴、斑点分布、整体画风。
- 情绪表达示例：委屈（眼角下垂+眉毛下压）、无语（死鱼眼+挑眉）、开心（眯眼笑+张嘴露舌）、震惊（圆眼瞪大+嘴巴张大）。

## 5. 贴纸化建议 (Sticker-ization Notes)

- 适合表情：无语 / 生气 / 委屈 / 震惊 / 偷笑 / 求求了 / 开心 / 嫌弃——变化眼神、眉毛、嘴型与动作即可得到不同候选贴纸。
- 装饰元素：手帐虚线框、小花、星星、便签条、闪粉、气泡（保持手绘绘本 × 日系萌系画风）。
- 文案排版：圆体加粗 / 手写体，白色描边 + 深色字芯，横排或竖排均可，须保证 64px 缩放下可读。
- 斑点稳定性：跨贴纸复用同一套斑点分布描述（见 feature_map 对照表），避免每张图花纹漂移。
